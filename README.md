# Alien Shooter

A 2D alien-shooting game made with Python and Pygame.

## Download (Windows)

Download the latest `AlienShooter.exe` from the [Releases](../../releases) page. No Python installation is required.

## Developer Requirements

- Python 3
- Pygame

## Developer Installation and Running

1. Clone or download this repository.
2. Open a terminal in the `Alien Shooter` folder.
3. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

4. Run the game:

   ```bash
   python game.py
   ```
